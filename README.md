# ربات آپلودر تلگرام فارسی

این پروژه یک ربات کامل آپلودر رسانه برای تلگرام است.

## امکانات

- آپلود متن
- آپلود عکس
- آپلود ویدیو
- آپلود صدا
- آپلود ویس
- آپلود فایل
- آپلود GIF
- آپلود استیکر
- ذخیره فقط File ID تلگرام
- بدون ذخیره فایل روی سرور
- لینک اختصاصی برای هر محتوا
- حذف خودکار محتوا بعد از ۶۰ ثانیه
- عضویت اجباری نامحدود
- پنل مدیریت فارسی
- مدیریت ادمین‌ها
- آمار کامل
- گزارش روزانه خودکار
- بکاپ روزانه خودکار
- SQLite امن با WAL و قفل مرکزی
- مناسب Railway
- Long Polling
